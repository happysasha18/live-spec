# Method finding: a role-profile brief beat a plain brief in a blind A/B (tlvphotos, 2026-08-08)

From the tlvphotos window. A controlled worker-briefing experiment ran tonight and its
result is method-relevant beyond that project.

**Setup.** The same well-specified mechanical task (extend an animation module with an
external progress dial and external clock, prove with a headless check, fill a schema row)
was given to two identical-tier workers: one briefed with a short role profile (a
craftsman identity: the project's design charter as sole naming source, causal chains for
each rule, an interdict — escalate taste questions instead of deciding) plus the charter;
the other with the same functional spec in plain engineering words. Neither knew of the
other. A third, fresh agent judged the two patches unlabeled.

**Result.** The profile arm won on all three pre-registered criteria: vocabulary fidelity
(its checks read as the project's laws; the plain arm renamed the domain object), truth of
the documentation it wrote (the plain arm's schema row asserted a property the code does
not have; the judge disproved it against captured frames), and integration (house pattern,
smaller diff, and the only proven-green run). The plain arm was more ambitious in testing
method — two of its ideas were grafted onto the winner — but its two flagship proofs each
carried a real defect (an off-by-one at the measured edge; an exactness assertion that
ignores antialiasing).

**Readings for the pack.**
1. A ~25-line role profile with an escalation interdict measurably changed worker output
   quality on a same-model, same-spec task. Cheap to attach, worth considering as a
   standard brief layer wherever a project holds a design language.
2. Both arms independently found the same real shader defect the task never mentioned —
   two independent arms on one task double as a bug-finding instrument.
3. The blind-judge step caught a false documentation claim that both green suites missed:
   green checks plus a wrong sentence in the docs is a real failure mode, and only
   artifact-level adversarial review saw it.
