## F6 — The code-anchor scan misses the repository's own citation idiom and reds two lawful shapes

Probed against the shipped `find_hits` (10 samples, run 2026-07-27):

Missed — a naked code the law means to catch, passing silently:
- `ROADMAP 480 landed last night and the queue is clean.` — the citation idiom this repository uses in
  the architecture, the matrix and every prover record. The pattern list carries no document-name form.
- `INV 281 now reaches the whole turn.` and `M 402 covers the dramatization law.` — the code words are
  matched only with a hyphen (`INV-\d+`), so the spaced form, which is how the codes read aloud, passes.
- `row #386 is still open.` — `rows?\s+\d+` needs digits directly after the space.
- `486 goes first, then the legibility fix.` — a bare number, excluded by design (the docstring says the
  net reads the naming, not arithmetic), yet it is the shape a hurried reply actually produces.
- `| row 386 | | |` — a table line is skipped whole on the stated assumption that the neighbouring cell
  carries the plain words. Nothing checks that cell, so a one-column table of row numbers passes.

Wrongly red — a lawful sentence the scan blocks:
- `Ошибка в строке 484 файла PRODUCT_SPEC.md` — in the working language of these sessions the naming word
  means a file's line, not a queue row. Pointing at line 484 of a document is a plain, resolvable fact,
  and the hook reds it.
- A parenthetical broken across a line — `... open (row 386,\nand row 412 too).` — reds, because the
  bracket pattern excludes newlines while the anchor it protects does not.

The first class is the honest cost of a literal list and belongs in the docstring's boundary paragraph
next to what is already stated there; the document-name form and the spaced code form are worth adding
outright, since both appear in this repository's own prose daily. The second class is the one that costs
trust: add `\n` tolerance to the bracket span, and carve the file-line reading (a naming word followed by
a number and a file name) out of the pattern.
