## The findings and their fate

Ten must-fix, twelve should-fix, one recorded.

**Settled before building, and carried into the landed design.**

- **F3 — the gate ran a shell string out of the data file while the design claimed it did not.** The
  registry now carries an argument list rather than command text. Each stage starts with no shell,
  through a seven-program read-only allowlist, with patterns expanded inside the repository root, and
  the reader's published copy of the command is rendered from the same list the gate runs. The
  registry says of itself that an argument-list edit is a code change.
- **F6 — the registry's fields could not render the law the design wrote.** A count now carries seven
  named parts of ground, and the generator refuses an entry that leaves one of them empty. An empty
  baseline, direction or target is accepted only with a written reason.
- **F7 — two of the three page edits wrapped a sentence in the middle of a paragraph.** The rules
  paragraph on `README.md` is split so the generated block stands on its own between two authored
  paragraphs, and the two counts that needed no new prose entered the registry as sentence homes with
  their sentences untouched.
- **F25 — the landing moves the tree it measures.** The generator runs last in the landing order, after
  every other edit, and this session ran it last.

**Answered by the slice, which drops the mechanism the finding was about.**

F1 (the census reads digits while eight of the counts are written as words), F2 (a declared page has
no field), F4 (the chat arm's counted-noun test is undefined), F5 (the weak-word gate runs on no

**Repaired in the design's own text.** F9, the design stated a count of its own that was wrong, and
F10, the replacement worker-run count was not reproducible. The number left that sentence; the class
and the command stayed.

**Recorded with a reason.** F22, the prover-record glob is ambiguous by 21 entries. The claim is a
floor both readings clear by a wide margin, so the count entered the registry as an at-least
measurement with a floor of 300 records.

## What the landing did not do, said plainly

The gate reads whether a published count matches the tree. It reads nothing about whether the count
is worth publishing, whether the decision named beside it is the real decision, or whether the ground
the paragraph gives is the right ground. That sentence stands in the gate's own header, on its green
reach line, and in the requirement's closing criterion.

Four surfaces the owner's ask also covers stay unheld: a number a session writes into chat, a number
in an artifact rendered for one showing, a count published inside a shipped skill body, and a count on
a page nobody thought to declare. Each has its later row in the design's Part 8.
